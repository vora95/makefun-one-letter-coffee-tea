One Letter: Coffee or Tea — **A** for coffee. A deterministic Python 3 program (standard library only, no network) that writes exactly one character, the letter A, to `/output/entry.txt`. Coffee is the vivid answer: bold, dark, aromatic, a jolt that lands alive — funnier (caffeine, "don't talk to me before my first cup") and truer (builders run on coffee) than tea's calm cup.

## Run it

```sh
python3 main.py
```

The program writes a single byte, `0x41` (A), to `/output/entry.txt` — no newline, no extra text. The output is byte-identical on every run.
